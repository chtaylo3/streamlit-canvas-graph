# Security policy

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue or pull request.
Use GitHub private vulnerability reporting for this repository. Include affected
versions, reproduction details, impact, and any suggested mitigation.

The maintainer will acknowledge a report as soon as practical, investigate it,
and coordinate disclosure and remediation with the reporter. No fixed response
or resolution time is guaranteed.

## Supported versions

Security fixes are applied to the current `main` branch. Until the project begins
publishing stable releases, older commits and development snapshots are not
separately supported.
